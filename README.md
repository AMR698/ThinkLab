# ThinkLab – مهارة Claude لتحليل أفكار المشاريع

مهارة (Skill) لـ claude.ai بتاخد فكرة مشروعك وتمشي معاك **خطوة بخطوة**، وكل مرحلة تطلعلك **PDF (و Word)** بنفس شكل
ملفاتك: عربي من اليمين للشمال، عناوين وردي وسماوي، "يجب مراعاة الآتي" بالأحمر، كروت `Card 1: ...`، ورحلات شاشة بشاشة.

## المراحل
| # | المرحلة | الملف اللي بيطلع |
|---|---|---|
| 1 | تحليل الفكرة + أفكار واقعية تضيفها + يجب مراعاة الآتي + الناف بار | `01 تحليل الفكرة` |
| 2 | مميزات النظام ومميزات كل مستخدم (كروت) | `02 مميزات النظام` + `03 مميزات المستخدم` |
| 3 | تحليل السوق (بحث على النت بمصادر) | `04 تحليل السوق` |
| 4 | المنافسين وأسعارهم والفجوات | `05 المنافسين` |
| 5 | التسعير والباقات وتكلفة التطوير | `06 التسعير` |
| 6 | الهيكل الرئيسي ورحلة كل مستخدم | `07 الهيكل ورحلة ...` |
| 7 | الرحلة التفصيلية شاشة بشاشة (أزرار، حالات خطأ ونجاح) | `08 الرحلة التفصيلية - ...` |

بعد كل مرحلة بتسألك: "موافق نكمل؟ ولا تعدّل؟" ومش بتكمل غير لما توافق.

## إزاي ترفعها على claude.ai
1. نزّل الملف `dist/thinklab.zip`.
2. ادخل على claude.ai ← **Settings** ← **Capabilities** وتأكد إن **Code execution and file creation** شغال.
3. في نفس الصفحة في جزء **Skills** اضغط **Upload skill** وارفع `thinklab.zip`، وتأكد إنها مفعّلة.
4. فعّل **Web search** في الشات عشان مراحل السوق والمنافسين والتسعير.

## إزاي تستخدمها
افتح شات جديد واكتب مثلًا:
> عندي فكرة مشروع: نظام لإدارة المخازن للشركات الصغيرة في مصر، حللها معايا بـ ThinkLab

## محتويات المهارة
```
thinklab/
  SKILL.md                 خطوات الشغل
  references/              تعليمات كل مرحلة + أسلوب الكتابة + صيغة الـ JSON
  scripts/build_doc.py     بيحوّل محتوى المرحلة لـ Word بنفس تنسيقك، وبعدين PDF
  assets/fonts/            خط Amiri العربي (رخصة OFL)
  examples/warehouse/      مثال فكرة المخازن
```

## تشغيل السكربت يدويًا (اختياري)
```bash
python3 thinklab/scripts/build_doc.py thinklab/examples/warehouse/*.json --out output
```
محتاج `python-docx` (السكربت بيسطبه لوحده لو مش موجود) و LibreOffice عشان يطلع الـ PDF.
