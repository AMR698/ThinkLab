# ThinkLab – مهارة Claude لتحليل أفكار المشاريع

مهارة (Skill) لـ claude.ai بتاخد فكرة مشروعك، **تتناقش معاك الأول**، وبعدين تطلعلك كل ملفات المشروع **PDF (و Word)** بنفس شكل
ملفاتك: عربي من اليمين للشمال، عناوين وردي وسماوي، "يجب مراعاة الآتي" بالأحمر، كروت `Card 1: ...`، ورحلات شاشة بشاشة.

## أولًا: النقاش (من غير ملفات)
1. **فهم الفكرة**: تعيد صياغة فكرتك وتسألك عن الناقص (السوق، المنصة، نموذج الربح...).
2. **مين اللي هيستخدم النظام**: تقترح كل أنواع المستخدمين وصلاحياتهم، وإنت تشيل وتضيف.
3. **المميزات لكل مستخدم**: أساسي / ⭐ مقترحات منها / مرحلة لاحقة، مرقمة، وإنت تختار بالأرقام.
4. **التأكيد**: ملخص اللي اتفقتوا عليه، ولما تقول "ابدأ" تطلع الملفات.

## ثانيًا: الملفات (تطلع كلها ورا بعض)
| الملف | المحتوى |
|---|---|
| `01 تحليل الفكرة` | المشكلة، الفئة المستهدفة، أفكار واقعية، SWOT، المخاطر، يجب مراعاة الآتي، الناف بار |
| `02 مميزات النظام` + `03 مميزات المستخدم` | كروت المميزات اللي اتفقتوا عليها |
| `04 الهيكل ورحلة <مستخدم>` | ملف لكل مستخدم: الواجهة الرئيسية، الملفات، الرحلات داخل كل ملف |
| `05 الرحلة التفصيلية - <ملف>` | شاشة بشاشة: الأزرار، حالات الخطأ والنجاح |
| `06 تحليل السوق` | حجم السوق وشرائحه واتجاهاته (بحث على النت بمصادر) |
| `07 المنافسين` | المنافسين وأسعارهم والفجوات |
| `08 التسعير` | الباقات وتكلفة التطوير ونقطة التعادل |

في الآخر بتسألك لو عاوز تعدّل في ملف معين، وتعيد توليد الملف ده بس. لو الرد اتقطع في النص اكتب "كمّل".

## تحديث المهارة بعد ما تكون رفعتها قبل كده
Settings ← **Skills** ← **thinklab** ← النقط التلاتة (⋮) ← احذفها، وبعدين **Upload skill** وارفع `thinklab.zip` الجديد.

## إزاي ترفعها على claude.ai
1. نزّل الملف `dist/thinklab.zip`.
2. ادخل على claude.ai ← **Settings** ← **Capabilities** وتأكد إن **Cloud code execution and file creation** شغال.
3. من القائمة الجانبية تحت **Customize** ادخل على **Skills** واضغط **+** ثم **Upload skill** وارفع `thinklab.zip`، وتأكد إنها مفعّلة.
4. فعّل **Web search** في الشات عشان مراحل السوق والمنافسين والتسعير.

## إزاي تستخدمها
افتح شات جديد واكتب مثلًا:
> عندي فكرة مشروع: نظام لإدارة المخازن للشركات الصغيرة في مصر، حللها معايا بـ ThinkLab

## محتويات المهارة
```
thinklab/
  SKILL.md                 خطوات الشغل
  references/              تعليمات كل مرحلة + أسلوب الكتابة + صيغة الـ JSON
  scripts/build_doc.py     بيحوّل محتوى المرحلة لـ Word بنفس تنسيقك، وبعدين PDF
  assets/fonts/            خط Amiri العربي (رخصة OFL)
  examples/warehouse/      مثال فكرة المخازن
```

## تشغيل السكربت يدويًا (اختياري)
```bash
python3 thinklab/scripts/build_doc.py thinklab/examples/warehouse/*.json --out output
```
محتاج `python-docx` (السكربت بيسطبه لوحده لو مش موجود) و LibreOffice عشان يطلع الـ PDF.
