# Stage 0 – جلسة النقاش (Discovery) – before ANY file

The user wants a real conversation before documents: who uses the product, which features, your suggestions,
and their choices. **Do not generate any PDF until round 4 is confirmed.** Never skip this stage, even when the
idea is detailed, unless the user explicitly says "من غير نقاش" / "اعمل الملفات على طول".

Rules for every round:
- One message per round, then STOP and wait for the reply.
- Egyptian Arabic, warm and short sentences. Use numbered lists so the user can answer with numbers.
- Use what the user already said; don't re-ask it. If they answer briefly ("تمام", "كمّل"), accept your recommendations.
- Keep a running "المتفق عليه" in your head; everything later must follow it.

## Round 1 – فهم الفكرة
1. Restate the idea in 2 lines the way you understood it.
2. Ask only what is missing (max 5 short questions), each with your suggested default in brackets, e.g.:
   - السوق: مصر ولا دولة تانية؟ وأي مدن نبدأ بيها؟ (اقتراحي: القاهرة والجيزة)
   - المنصة: موبايل، ويب، ولا الاتنين؟ (اقتراحي: ويب للإدارة + موبايل للتشغيل)
   - نموذج الربح: اشتراك شهري، عمولة، بيع مرة واحدة؟
   - الشريحة الأولى اللي هنبدأ بيها؟
   - فيه حاجة في دماغك لازم تكون موجودة أو منافس شايفه؟

## Round 2 – مين اللي هيستخدم النظام؟
List **every** user type you propose (usually 4–10), numbered. For each: name in bold, one line on what they do in the
product, and one line on what they can / cannot do (permissions). Mark the ones you recommend for the first version
with ⭐ and the ones for later with ⏳. Include non-obvious ones (viewer-only partner, external accountant, driver,
customer, supplier portal, super admin of the platform…). End with:
"تحب تشيل حد؟ تضيف حد؟ ولا نعتمد الـ ⭐ ونكمل؟"

## Round 3 – المميزات لكل مستخدم
For each agreed user type (1–2 user types per message if there are many; continue in the next message after the reply):
- **أساسي (MVP)** – numbered features without which the product does not work for this user.
- **⭐ مقترحات مني تميزك** – numbered smart / differentiating ideas (AI, automation, WhatsApp, offline, wow moments),
  each with a short "ليه؟".
- **⏳ مرحلة لاحقة** – numbered features that need data, integrations or budget.
Numbering is continuous across the whole message so the user can reply "شيل 4 و 17، ضيف كذا، انقل 22 للأساسي".
After the user types are covered, add **"أفكار واقعية تضيفها للمشروع كله"** (5–10 numbered cross-cutting ideas).
End with: "اختار بالأرقام: تشيل إيه؟ تضيف إيه؟ ولا موافق على كده؟"

## Round 4 – التأكيد
Summarise what was agreed in a compact message:
- الافتراضات (السوق، المنصة، نموذج الربح، الشريحة الأولى)
- المستخدمين المعتمدين
- عدد المميزات لكل مستخدم (أساسي / مقترح / لاحق) + أهم 5 مميزات مميزة
- قائمة الملفات اللي هتطلع بالترتيب (include one journey file per user and one detailed journey file per main module)
Then ask: **"كده تمام؟ أبدأ أطلع الملفات كلها ورا بعض؟"**

When the user confirms, move to file generation (see SKILL.md) without further questions.
